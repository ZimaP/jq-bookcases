# JQ Bookcases project instructions

## Production publication is part of completion

- The user has given standing authorization to deploy completed customer-facing website changes for this repository to the live production website.
- Unless the user explicitly requests local-only work or says not to deploy, a website change is not complete until it is committed, pushed, merged into `main`, published through the production workflow in `RELEASE.md`, and verified on the live URL.
- Never report a website task as complete based only on local implementation, tests, screenshots, a pushed branch, or a merged pull request.
- If publication or live verification is blocked, state clearly that the change is not live and report the exact blocker.
- Follow the SHA-locked production safety contract in `RELEASE.md`; standing deployment authorization does not permit bypassing its validation, tag, or workflow requirements.
